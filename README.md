# ab-testing-template

Шаблон-блокнот для дизайна и анализа A/B-тестов с **непрерывной метрикой** (ARPU, средний чек, время в сервисе и т. п.).

| Раздел | Что делает |
|---|---|
| 0. Параметры | α, мощность, MDE, трафик, сплит |
| 1. Рамка дизайна | гипотеза, метрики, критерии решения, чек-лист |
| 2. Калькулятор | размер выборки, длительность теста, графики (распределение метрики, n от MDE) |
| 3. Проверки сплита | A/A-тест, SRM, баланс на пре-периоде |
| 4. Анализ результатов | Welch t-test, доверительный интервал, бутстрап-ДИ для эффекта, guardrail-метрики (поправка Холма), решение |
| 5. Отчёт | сводка по эксперименту |
| 6. Типичные ошибки | список того, чего избегать |

## Данные

По умолчанию `USE_SYNTHETIC = True`: блокнот сам генерирует синтетические данные и запускается целиком.

Для реальных данных поставить `USE_SYNTHETIC = False` и положить рядом с блокнотом два файла:

- `history.csv` — история до теста: `user_id`, `metric` (одна строка на пользователя);
- `experiment.csv` — данные теста: `user_id`, `group` (`A` — контроль, `B` — тест), `arpu`, `arpu_pre` (метрика до старта) и guardrail-метрики.

Названия колонок настраиваются в ячейке раздела 4. В репозитории уже лежат `history.csv` и `experiment.csv` — синтетический пример для проверки блокнота «из коробки», можно заменить своими данными.

## Допущения

- Метрика непрерывная, unit рандомизации совпадает с единицей анализа.
- Два варианта (контроль и тест), двусторонний критерий.
- Расчёт выборки по нормальному приближению.
